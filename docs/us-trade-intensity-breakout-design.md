# 미국 단일 종목 체결강도 기반 급등주 탐지 설계

## 목적

KIS 해외주식 체결추이 API(`HHDFS76200300`)의 `vpow` 체결강도를 단일 순간값이 아니라 시계열 검증 신호로 사용한다. 이 API는 해당 날짜 전체 체결내역이 아니라 호출 시점 기준 최근 체결추이를 반환하므로, 반복 수집과 구간 비교가 필수다.

## API 경계

- 호출 모듈: `lib/kis-us-trade-trend.ts`
- 분석 모듈: `lib/us-trade-intensity-metrics.ts`
- 관리자 테스트: `/api/admin/kis-us-trade-trend-test`
- 거래소 코드: `NAS`, `AMS`, `NYS`
- 거래소 미입력 시 fallback: `NAS → AMS → NYS`
- 거래소 입력 시 해당 거래소만 조회
- 성공 조건: HTTP 성공 + `rt_cd=0` + 체결 배열 1건 이상
- 응답 배열: KIS 문서의 `output2`와 예제의 `output1` 모두 지원

## 수집 정책

1. 기본 30초 주기로 호출한다.
2. API 응답의 최근 체결을 `market + ticker + time + price + volume + totalVolume`으로 중복 제거한다.
3. 원본 체결과 수집 실행 결과를 별도 저장한다.
4. 장 구분(`mtyp`)을 `0=장중`, `1=장전`, `2=장후`로 분리한다.
5. 장전·장중·장후 데이터를 하나의 평균으로 섞지 않는다.

## 분석 지표

최근 체결 배열은 최신순으로 들어온다고 가정하고 동일 표본 수의 두 구간으로 나눈다.

- 최근 평균 체결강도
- 직전 평균 체결강도
- 체결강도 변화량
- 최근 체결강도 100 이상 유지 비율
- 최근 가격 변화율
- 최근·직전 체결량 변화율
- 매수·매도호가 스프레드
- 장 구분별 표본 수

표본이 4건 미만이거나 직전 구간이 2건 미만이면 데이터 품질을 `INSUFFICIENT`로 표시하고 후보 판정을 금지한다.

## 기본 점수

| 조건 | 점수 |
|---|---:|
| 최근 평균 체결강도 100 이상 | 20 |
| 최근 평균 체결강도 120 이상 | 15 |
| 직전 구간 대비 체결강도 상승 | 20 |
| 체결강도 100 이상 비율 60% 이상 | 15 |
| 분석 구간 가격 상승·보합 | 10 |
| 최근 체결량 증가 | 10 |
| 스프레드 2% 이하 또는 미제공 | 5 |

- `80점 이상`: `STRONG`
- `60~79점`: `WATCH`
- 그 미만: `REJECT`
- 표본 부족: 점수와 무관하게 `REJECT`

## 급등주 결합 필터

체결강도만으로 Discord 알림을 보내지 않는다. 다음을 함께 검증한다.

```text
체결강도 추세 상승
+ 평균 체결강도 100 이상
+ 가격 등락률 0% 이상
+ 거래량 RVOL 1.5 이상
+ 시총 대비 거래대금 1% 이상
+ 호가 스프레드 2% 이하
```

체결강도가 오르지만 가격이 하락하거나 거래량이 감소하면 매수세 확정으로 판단하지 않는다.

## 알림 상태

```text
NORMAL → WATCH → QUALIFIED → ALERTED → COOLDOWN
```

동일 종목의 반복 알림은 기본 10분 cooldown을 둔다. 재알림 시간과 점수·체결강도·거래대금 기준은 관리자 설정으로 분리한다.

## 관리자 디버깅 요구사항

관리자 테스트는 다음을 모두 표시해야 한다.

- 요청 거래소와 실제 해결 거래소
- fallback 시도 순서
- HTTP 상태와 `rt_cd`, `msg_cd`, `msg1`
- 원본 응답과 파싱 배열 키
- 수신 체결 수·중복 제거 수
- 최근·직전 평균 체결강도
- 체결강도 변화량과 100 이상 유지율
- 가격·거래량·스프레드 지표
- 필터별 통과·탈락 사유
- 최종 점수와 `STRONG/WATCH/REJECT`

관리자 테스트의 Discord 전송은 기본적으로 미리보기만 수행하고, 실제 알림 전송은 별도 명시적 옵션으로만 허용한다.

## 구현 순서

1. 현재 완료: API 클라이언트, `output1/output2` 파서, 거래소 fallback, 순수 지표·점수 모듈, 관리자 테스트 연결
2. 다음: 체결 원본·수집 실행 DB 저장소와 중복 제거
3. 다음: 30초 수집 자동화 및 장 구분별 시계열 집계
4. 다음: 시총 대비 거래대금·RVOL·가격 필터와 결합
5. 다음: 상태 전이·cooldown·Discord 알림
6. 운영 전 검증: 관리자에서 정상·빈 응답·API 오류·표본 부족·잘못된 거래소를 각각 재현

## 금지 사항

- 체결강도 단일값만으로 급등주 확정
- 표본 1~3건을 추세로 간주
- 장전·장중·장후 평균 혼합
- KIS 오류 응답을 정상 데이터로 저장
- 테스트 실행이 자동 Discord 알림을 발생시키는 동작
- `NYS`를 `NYSE`로 API에 전송
