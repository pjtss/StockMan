# OpenDART 재무제표 수집 명세

공식 기준: [OpenDART 개발가이드](https://opendart.fss.or.kr/guide/main.do)

## 저장 차원

- 회사 식별자: `corp_code`, 종목코드
- 보고서: 사업보고서·반기보고서·분기보고서
- 보고기간: 사업연도, 보고기간, 시작일, 종료일
- 재무제표: 재무상태표, 손익계산서, 현금흐름표, 포괄손익계산서
- 계정: 계정코드, 계정명, 당기·전기·전전기 값
- 연결 구분: 연결·별도
- 원문 추적: 접수번호, 제출일, API 수집일시

## 표준화 시 주의사항

- 숫자값과 표시용 문자열을 분리한다.
- 단위·통화·연결 여부를 함께 저장한다.
- 계정명만으로 계정을 식별하지 않고 공식 계정코드와 원본 계정을 보존한다.
- 정정 공시가 있으면 최신 제출본을 현재값으로 사용하되 이전 제출본도 이력으로 남긴다.

## 프로젝트 저장 연결

표준 테이블은 `financial_statements`, 원문은 `financial_source_documents`, 수집 실행은 `financial_sync_runs`와 `financial_sync_failures`로 분리한다.
