# 국내 기업 투자분석 JSON 내보내기 설계

## 목적

`기타` 페이지에서 국내 보통주 전체의 원천 데이터와 LLM 입력용 통합 데이터를 재현 가능한 JSON으로 다운로드한다. 이 파일은 투자 조언이 아니라 분석용 데이터셋이다.

## 데이터 계층

1. **원천(raw)**: DB에 저장된 KIS/OpenDART 원본 payload를 변경하지 않고 종목 식별자, 출처, 수집시각과 함께 보존한다.
2. **정규화(normalized)**: 프로젝트의 재무 스냅샷 컬럼을 공통 필드명으로 제공한다.
3. **LLM 통합(llm)**: 정규화 재무 데이터와 DB에 저장된 최신 일·주·월봉을 한 종목 객체에 묶는다.

## 포함 필드

- 식별: 시장, 종목코드, 종목명, 표준코드
- 재무 스냅샷: 가격, 시가총액, 거래량, 거래대금, 유통주식수, 통화
- 재무 원본: `rawPayload`
- 기술 데이터: 일봉·주봉·월봉의 OHLCV, 기준일, 갱신시각, 원본 payload
- 파일 메타데이터: 포맷, 생성시각, 건수, 시장

현재 DB에 존재하지 않는 PER·PBR·ROE·성장률·OBV·ADL·EMA는 임의로 0이나 추정값을 넣지 않는다. 해당 원천 수집 및 계산 모듈이 추가되면 `financialMetrics`와 `indicators` 네임스페이스로 확장한다.

## API

`GET /api/domestic-financial-export`

- 기본값: 정규화 데이터
- `?format=raw`: 원천 payload 중심
- `?format=llm`: 재무 + 일·주·월봉 통합
- 응답은 UTF-8 JSON attachment이며 비밀 환경변수는 절대 포함하지 않는다.

## 수집 및 품질 원칙

- 데이터 기준일과 `fetchedAt`을 분리한다.
- 결측은 `null`로 유지하고 0으로 대체하지 않는다.
- 보통주만 포함하며 ETF·우선주·파생상품은 유니버스 조건으로 제외한다.
- LLM에 전달할 때도 원천 payload를 삭제하지 않고 정규화 값과 병기한다.
- 내보내기 시점의 스키마/계산 버전을 메타데이터에 추가할 수 있도록 포맷을 버전 관리한다.

## 후속 확장

- OpenDART 재무제표 일괄 원문(XBRL) 수집 작업과 `financial_statement_snapshots` 분리 저장
- KIS 재무비율(PER/PBR/EPS/BPS, 수익성·안정성) 스냅샷 저장
- EMA(9/20/60), 볼린저밴드, RVOL, OBV·ADL 계산 결과 저장
- 업종별 상대 밸류에이션과 투자 후보 점수는 원천 데이터와 분리된 `investment_candidate_scores`에 저장
- 대량 작업은 관리자 실행 → 비동기 작업 → export ID → 다운로드 흐름으로 전환
