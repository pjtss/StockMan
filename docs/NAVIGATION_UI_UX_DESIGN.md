# 네비게이션 바 UI/UX 설계 및 구현 기준

## 목적

주요 기능으로 빠르게 이동하면서도 현재 위치를 명확히 인지할 수 있는 데스크톱·모바일 공통 네비게이션을 제공한다.

## 메뉴 범위

- 홈: `/`
- DART: `/dart`
- 티커 차트: `/charts`
- 알림 설정: `/notifications`

관리자 메뉴는 보안상 네비게이션에 노출하지 않는다. 관리자 페이지와 API의 인증 경계는 별도로 유지한다.

## 동작 및 접근성

- 모든 링크는 `prefetch={false}`로 불필요한 초기 요청을 줄인다.
- 현재 페이지 링크에는 `aria-current="page"`를 적용한다.
- 헤더 브랜드는 홈 링크이며 접근 가능한 이름을 제공한다.
- 네비게이션에는 `aria-label="주요 메뉴"`를 적용한다.
- 키보드 사용자는 `:focus-visible` 외곽선으로 현재 포커스를 확인할 수 있다.
- 모바일 링크의 최소 높이는 44px로 유지한다.

## 반응형 규칙

- 데스크톱: 브랜드·메뉴·테마 토글을 한 줄에 배치한다.
- 모바일: 메뉴를 가로 스크롤 탭으로 제공하고 스크롤바는 숨긴다.
- 모바일에서 페이지 전체 가로 오버플로가 발생하지 않도록 헤더는 `max-width: 100%`를 유지한다.
- `prefers-reduced-motion` 사용자는 로고 애니메이션과 전환 효과를 보지 않는다.

## 변경 범위

구현 기준 파일은 `components/page-navigation.tsx`와 `components/page-navigation.module.css`다. 메뉴 경로와 관리자 인증 기능은 이 컴포넌트에서 변경하지 않는다.
