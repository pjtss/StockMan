# 종목별 최신 일봉 요약 캐시 설계

## 목적

대형 원본 캔들 테이블을 매번 집계하지 않고, 종목별 최신 정상 일봉 1개를 빠르게 조회한다.

## 원칙

- 원본 `*_instrument_universe_candles` 데이터는 삭제하거나 대체하지 않는다.
- 거래량이 0 이하이거나 종가가 없는 봉은 요약 캐시에 반영하지 않는다.
- KIS 적재 성공 후에만 요약 캐시를 upsert한다.
- 갱신 실패 시 기존 요약 행을 유지한다.
- 스크리너는 최신 거래일 검증과 최신 가격·거래량 조회에 요약 캐시를 사용한다.

## 테이블

`kr_latest_daily_candles`, `us_latest_daily_candles`에 시장·티커별 최신 일봉을 저장한다. `(market, code)`를 기본 유일키로 사용한다.

## 갱신 흐름

`KIS 조회 → 원본 bulk upsert → 최신 일봉 후보 검증 → 요약 캐시 upsert`

초기 도입 시 V114 backfill을 실행하고, 이후 일봉 저장 함수가 자동 갱신한다.

## 스크리너 적용

최신(`LATEST`) 종목 추천은 V114 요약 캐시를 통해 최신 거래일과 최신 봉 존재 여부를 확인한다. 특정 기준일(`asOf`) 조회는 과거 시점 재현을 위해 원본 캔들 테이블을 사용한다. V116은 활성·일봉 활성·보통주 조건과 최신 재무 조회를 위한 스크리너 전용 인덱스를 추가하고, V117은 지표 계산에 필요한 OHLCV 조회를 커버링 인덱스로 보완한다.

국내 일봉 작업이 대상 종목을 처리했지만 usable candle을 한 건도 저장하지 못하면 작업을 성공 완료로 기록하지 않고 실패로 기록한다. 이를 통해 빈 캐시 상태를 정상 완료로 오인하지 않고 자동화 이력과 알림에서 즉시 확인할 수 있다.
