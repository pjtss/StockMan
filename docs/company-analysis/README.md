# 기업 분석 문서 인덱스

대한민국 국내 주식과 미국 주식 기업의 공시·사업·재무·임상·희석 위험 분석 결과를 이 폴더 아래에서 관리한다. 그 외 국가의 주식은 분석 대상이 아니므로 별도 보관소를 두지 않는다.

## 시장별 보관소

- [대한민국 기업 분석](./kr/README.md): 한국거래소 상장 종목 분석.
- [미국 기업 분석](./us/README.md): 미국 거래소 상장 보통주 분석. 발행사 국적과 무관하게 미국 거래소 상장·SEC 공시 분석은 여기에 둔다.

## 분류 및 파일 관리 규칙

- 대한민국·미국 주식만 관리한다. 그 외 국가의 거래소 상장 종목은 분석·보관 대상에서 제외한다.
- 국내 보고서는 종목코드와 기준일, 미국 보고서는 티커와 기준일을 제목과 경로에 명시한다.
- 단일 기업 분석 파일명은 `<TICKER>-YYYY-MM-DD-<topic>.md`를 기본으로 한다. 여러 기업을 한 번에 검토한 cohort는 별도 하위 폴더와 README 인덱스를 둔다.
- 보고서에는 회사 법인명, 티커, 상장시장, 기준일/시간대, 조회·갱신 시각, 공식 1차 출처, 확인된 사실, 위험·반대 근거, 미확인 항목을 기록한다. 숫자는 통화·단위·기준일을 붙이고 추정과 확인 사실을 분리한다.
- 기준 자료를 복사해 중복 저장하지 않는다. SEC filing별 원문 검토는 기존 [SEC EDGAR accession 기록소](../../reports/sec-edgar-analysis/README.md)를 원본으로 유지하고 미국 인덱스에서 연결한다.
- 투자 판단·목표가·예상 수익률을 사실처럼 쓰지 않는다. 공식 자료가 없는 수치는 미공개/미확인으로 둔다.

## 현재 기록

한국 종목 분석은 국내 인덱스, 미국 공시 분석은 기존 SEC EDGAR accession 기록소와 미국 인덱스를 기준 자료로 사용한다. 새 분석 문서를 추가할 때 해당 시장 인덱스와 `docs/README.md`를 함께 갱신한다.
