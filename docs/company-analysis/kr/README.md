# 대한민국 기업 분석 문서

대한민국 주식시장 상장 기업의 공시·사업·재무·임상·희석 위험 분석 결과를 관리한다. 미국 및 대한민국 외 국가의 종목은 이 보관소의 대상이 아니다.

## 누적 기업 분석

현재 이 보관소에는 별도 등록된 기업 분석 보고서가 없다. 신규 분석은 종목코드와 기준일을 포함한 `<종목코드>-YYYY-MM-DD-<주제>.md` 형식으로 저장하고 이 인덱스에 연결한다.

## 기록 기준

- 회사 법인명, 종목코드, 거래소, 분석 기준일과 시간대를 기록한다.
- DART, 거래소, 회사 IR 등 공식 원문과 게시·접수 시각을 기록한다.
- 재무·주식수·가격은 기준일과 단위를 표시하고 확인값과 계산·추정값을 구분한다.
- 사업 현황, 촉매, 위험·반대 근거와 미확인 항목을 나누며 공식 자료에 없는 수치는 추정으로 채우지 않는다.
- 후속 자료가 나오면 기준일별 이력을 남기고 이 인덱스를 갱신한다.
