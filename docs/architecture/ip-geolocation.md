# IP 기반 지역 추론 설계

## 목적

요청 로그의 IP에서 국가·지역·도시·시간대·ASN을 대략 추정해 관리자 화면에서 확인한다. IP 위치는 실제 주소나 사용자의 정확한 위치가 아니며, 조회 실패 시 `unknown`으로 저장한다.

## 구조

`middleware`가 요청을 수집하고 `/api/internal/request-log`가 `getRequestIdentity()`와 `resolveIpLocation()`을 호출한다. 지역 조회는 독립 모듈(`lib/ip-geolocation.ts`)로 분리해 공급자 변경과 실패 격리를 보장한다.

기본 동작은 개인정보와 비용을 고려해 외부 API를 호출하지 않고 `unknown`을 저장한다. 운영자가 승인한 GeoIP 공급자를 연결할 때만 `IP_GEOLOCATION_API_URL`을 설정한다. 공급자 장애·잘못된 응답·사설 IP는 요청 처리를 중단시키지 않는다.

## 저장

`request_logs`에 국가 코드·국가명·지역·도시·시간대·ASN·기관·출처·신뢰도를 저장한다. 원본 IP는 관리자 전용이며 일반 사용자 화면에는 노출하지 않는다.

## 검증 기준

IPv4·IPv6·사설 IP·잘못된 IP·공급자 미설정·네트워크 오류·불완전한 응답을 테스트한다. 지역 정보는 보안·운영 분석 목적에 한해 사용하고, 개인정보 처리방침과 보존 기간 정책을 함께 관리한다.
