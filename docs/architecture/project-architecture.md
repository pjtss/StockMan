# StockMan 프로젝트 구조 및 운영 기준

## 제품 목적

국내·해외 주식의 실제 시장 데이터를 수집하고, 공통 적격성 필터와 기술적·수급·공시 신호를 결합해 관찰 후보를 Discord로 전달한다.

## 계층

1. **수집**: KIS, SEC EDGAR, DART, StockTitan, FINRA, FMP/대체 출처
2. **캐시·저장**: PostgreSQL 원본/정규화 데이터와 `automation_runs` 실행 이력
3. **적격성**: ETF·레버리지·워런트·파생상품 및 공통 가격·유동성 필터
4. **신호**: 일·주·월봉, OBV, ADL, MACD, DMI, MFI, 볼린저밴드, 돌파, 거래량
5. **전달**: 종목별 통합 결과, Discord Webhook, 관리자 원본·디버깅 화면

## 데이터 계약

- 비율은 저장 시 소수로 통일한다. `0.25 = 25%`.
- 화면·Discord에서만 퍼센트로 변환한다.
- 금액·가격은 원본 통화와 단위를 결과에 함께 표시한다.
- 모든 탐지 결과에는 기준일, 수집 시각, 캐시 여부, fallback 여부를 보존한다.
- 운영 환경에서는 임의 Mock 데이터를 반환하지 않는다. 데이터가 없으면 `UNAVAILABLE` 또는 빈 결과를 반환한다.

## 자동화 상태

모든 예약 작업은 `automation_runs`에 `RUNNING`, `SUCCESS`, `FAILED`, `SKIPPED` 중 하나로 기록한다. 완료 알림은 국내·해외 일봉 캐시, 해외 시가 캐시, 해외 유통주, 해외 상품분류 갱신에 적용하며, 관리자 설정 또는 `AUTOMATION_COMPLETION_DISCORD_WEBHOOK_URL`로 제어한다. 알림 결과는 `summary.notifications.completion`에 함께 기록한다.

## 제품 우선순위

신규 지표 추가보다 공통 필터, 통합 점수, 중복 알림 제거, 데이터 최신성·실패 원인 표시를 우선한다.

## 일봉 통합 점수

`runUsDailyFilterRefresh`는 기존 지표별 결과를 변경하지 않고 종목 티커 기준으로 통합 점수를 계산한다.

| 신호 | 배점 |
|---|---:|
| 일봉 돌파 | 25 |
| OBV | 20 |
| ADL | 20 |
| MACD | 15 |
| DMI | 10 |
| MFI | 10 |

- 70점 이상: A등급
- 45~69점: B등급
- 44점 이하: C등급

이 점수는 매수 추천이 아니라 여러 독립 신호가 같은 종목에서 동시에 충족되는 정도를 요약한 운영 지표다.

## 운영 완료 기준

새 자동화 기능은 다음 조건을 모두 만족해야 운영 등록 대상으로 인정한다.

1. OCI cron 또는 수동 실행 경로가 하나의 application service를 호출한다.
2. 실행 결과가 `automation_runs`에 저장되고, `SKIPPED`와 `FAILED`가 구분된다.
3. 외부 알림 실패가 데이터 수집 실패로 전파되지 않는다.
4. 관리자 화면에서 최근 실행·소요 시간·원본 요약·알림 결과를 확인할 수 있다.
5. 운영용 Mock 데이터가 없고, 데이터 부재·fallback·원본 시각이 결과에 표시된다.
6. 단위 테스트와 TypeScript·프로덕션 빌드 검증이 통과한다.
