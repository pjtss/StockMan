# 관리자 기능 모듈 그룹

관리자 `/admin/modules`는 기능을 한 목록에 평면적으로 나열하지 않고 다음 그룹으로 접어서 관리한다.

1. 시장 데이터·캐시
2. 볼린저밴드 탐지
3. 일봉 지표·추세 탐지
4. 실시간 수급·거래 탐지
5. 뉴스·공시 수집·알림
6. 공매도·대차
7. 운영·알림 관리

각 그룹은 HTML `details` 접기 구조를 사용하며, 첫 번째 그룹만 기본으로 펼친다. 카드는 기능 키, 자동화 상태, 설명, 설정 경로를 표시한다. 새 기능을 추가할 때는 `FEATURE_MODULES` 등록과 이 페이지의 그룹 키를 함께 갱신해 고아 기능이 생기지 않도록 한다.
