# 모바일 UI/UX 최적화 설계안

## 목표

390px 안팎의 모바일 화면에서도 주요 페이지가 가로로 잘리지 않고, 입력·탭·버튼을 손가락으로 조작하기 쉽도록 한다. 기존 데스크톱 레이아웃과 색상 토큰은 유지하며 모바일 구간에서만 밀도와 배치를 조정한다.

## 적용 범위

- 공통 페이지 셸과 히어로 영역
- 상단 내비게이션의 가로 스크롤 및 터치 영역
- 차트 조회 조건, 추출 결과 카드, 차트 모달
- 문의·공지·RSS 화면의 도구 영역과 목록
- 테이블·코드·JSON은 내용이 잘리지 않도록 내부 가로 스크롤을 사용

## 구현 원칙

1. 뷰포트 밖으로 나가는 고정 너비를 제거하고 `min-width: 0`을 우선 적용한다.
2. 버튼과 탭은 최소 44px 높이로 유지한다.
3. 모바일에서는 1열 배치를 기본으로 하고, 의미가 유지되는 정보만 2열로 둔다.
4. 긴 회사명·티커·오류 메시지는 줄바꿈하며, 원문 데이터는 별도 스크롤 영역으로 보존한다.
5. `prefers-reduced-motion` 사용자의 애니메이션은 기존 정책대로 축소한다.

## 검증 계획

- 360px, 390px, 430px 뷰포트에서 주요 경로를 확인한다.
- `document.documentElement.scrollWidth <= window.innerWidth`로 전역 가로 오버플로를 점검한다.
- 모바일 터치 대상의 높이와 포커스 표시를 확인한다.
- 단위 테스트, 타입 검사, 문서 검사, 빌드 및 standalone 런타임 smoke test 후 배포한다.
