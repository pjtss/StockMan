## 분류·데이터 한계

- 표준산업분류 코드 158개로 세부 집계를 완료했다. 2,548/2,548 종목의 코드는 확인했다. KIS 응답에서 20종목의 분류명이 비어 있었고, 이들은 7개 코드(147601, 147603, 031009, 147602, 106003, 137106, 033004)에 속한다. 동일 코드의 다른 응답에서도 이름을 확인하지 못해 명칭 대신 코드를 유지했다.
- KIS 주식기본조회는 단일 객체 output으로 응답하는데, 프로젝트 fetchDomesticStockInfo 공통 변환기는 배열 output만 읽어 빈 rows를 돌려보내는 문제가 확인됐다. 이번 보고서는 공통 kisRequest의 원본 parsed.output 객체를 직접 읽어 해결했으며, 제품 코드는 변경하지 않았다. 후속으로 어댑터 수정 및 객체형 응답 회귀 테스트가 필요하다.
- 로컬 DB에는 V160 표준산업분류 컬럼이 아직 적용되지 않아 조회 결과를 DB에 저장하지 않았다. 거래대금은 종가×거래량 추정이 아니라 KIS 종목별 일봉의 acml_tr_pbmn 실제 보고값을 사용했다. KIS 분류는 기업의 모든 사업을 포괄하는 매출 기준 업종이 아니라 KIS 종목 분류다.
