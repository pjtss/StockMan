# 해외 뉴스 탭 자동 갱신

## 동작

- 해외 뉴스(`/market-news`) 화면은 최초 진입 시 저장된 뉴스 API를 조회한다.
- 화면이 보이는 동안 10초마다 `/api/market-news`를 다시 요청한다. 브라우저 탭이 숨겨져 있으면 주기 요청을 건너뛰고 다시 보일 때 즉시 갱신한다.
- 이미 이전 요청이 진행 중이면 새 요청을 시작하지 않아 겹치는 API 요청을 방지한다.
- 출처 필터가 바뀌면 해당 출처 결과를 즉시 조회하고, 이후 갱신도 같은 필터를 유지한다.
- 갱신 실패 시 기존 결과를 유지하고 화면에 재시도 안내를 표시한다.

## 검증 기준

- 화면 테스트에서 초기 조회 후 10초 타이머가 추가 조회를 발생시키는지 확인한다.
- 타이머가 여러 주기 지나도 요청이 겹치지 않는지 확인한다.
- 배포 검증(`npm.cmd run deploy:verify`)과 `/market-news` 실행 확인을 통과시킨다.

## 변경 기록
