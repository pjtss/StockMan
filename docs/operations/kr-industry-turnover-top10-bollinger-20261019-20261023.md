> **자료 범위:** 최신 완료 거래주 2026-10-19~2026-10-23. 운영 KIS 일봉 응답 최신 거래일은 20261028. 운영 read-only candle API의 최신 거래일은 2026-10-26이며 응답은 OHLCV만 포함한다. 이후 거래대금 acml_tr_pbmn이 없어 해당 완료 주간을 사용했다.

## 집계 방법

- 거래대금: KIS FHKST03010100 응답의 실제 acml_tr_pbmn을 활성 보통주 기준으로 5거래일 합산. 산업 분류는 KIS CTPF1002R 표준산업 코드·명칭. 전체 2,548종목을 158개 산업 코드로 집계했다. 분류명 미제공 코드 7개(20종목)는 코드 표기로 별도 포함했다.
- Bollinger: 운영 GET /api/kis/market-flow?market=KR&code=...&mode=daily-price&period=D 응답의 OHLC로 로컬 계산. 최근 20개 종가 SMA, 모집단 표준편차, 하단=SMA−2σ. 프로젝트 정의대로 최신 또는 직전 봉 종가가 해당 봉의 하단 이하일 때 터치로 판정.
