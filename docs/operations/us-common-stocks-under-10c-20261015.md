# 지정 미국 보통주 7종 요약: $0.10 이하·시가총액 $5억 이하 (2026-10-15)

## 목적과 기준

2026-10-15 후속 요청에서 지정한 AZTR, AXG, DKI, HODO, SDST, SXTC, TWG 7개만 다시 정리했다. 기존 조건인 현재가 주당 USD 0.10 이하, USD 시가총액 USD 500,000,000 이하를 적용했다. 주식 수 단위는 상장주수를 기본으로 하며 1만 주와 1억 주 단위로 환산한다.

- 대상: 사용자가 지정한 티커 7개. 최초 조사에서 로컬 공식 유니버스의 활성 `COMMON_STOCK`로 확인됨. ETF·워런트·파생·DR·레버리지·인버스 제외 기준을 유지했다.
- 시세·시총: 운영 read-only API `GET /api/public/instrument-fundamentals`; `currency=USD`, 양수 가격 및 시총, 가격 ≤ 0.10, 시총 ≤ 500,000,000.
- 주식 수: 프로젝트 [상장주수 출처 정책](../architecture/listed-shares-source-policy.md)에 따라 KIS 상세시세 `output.shar`가 저장된 `listedShares`만 사용한다. 다른 출처의 발행주식수나 free float로 대체하지 않는다.
- 재조회 시각: 2026-10-15 16:03:02 KST (2026-10-15 07:03:02 UTC).
- 가격·시총 후보의 관측시각: 2026-10-14 18:43:59–18:44:18 UTC (2026-10-15 03:43:59–03:44:18 KST). 조회한 스냅샷은 운영 DB 저장값이며 실시간 재조회값이라고 간주하지 않는다.

## 커버리지와 제한

- 사용자 지정 티커 7개를 2개 배치 GET으로 재조회했다. 두 요청 모두 성공했고 응답에서 7개 모두 확인했다.
- 7개 모두 현재가 ≤ USD 0.10, USD 시가총액 ≤ USD 500,000,000이었다. 7개 전부 운영 응답상 `listedShares`가 미제공이었다.
- 이번 결과는 지정 7개의 가격·시총 조건 재확인이다. 상장주수 기준 및 만/억 단위 환산은 운영 API 응답에 상장주수가 포함될 때 확정할 수 있다.
- 대상 분류는 공식 종목 마스터 기반 프로젝트 유니버스의 활성 `COMMON_STOCK` 분류를 따랐다. 다만 운영 종목 마스터 원본 갱신일은 이번 조사에서 별도로 확인하지 못했다.

## 재현·보안

절차와 민감정보 취급 규칙은 [미국 소형주 추출 운영 절차](./us-small-cap-extraction.md)를 따른다. 종목 유니버스는 localhost DB에서 읽고, 운영 서버는 인증된 GET만 호출했다. 운영 DB 직접 접속, 데이터 갱신·저장, 자격증명 출력은 하지 않았다.

공식 기준 문서: [KIS Developers 종목 정보 파일](https://apiportal.koreainvestment.com/), 프로젝트 [상장주수 출처 정책](../architecture/listed-shares-source-policy.md). 이번 결과의 가격·시총·주식수 원천은 KIS 기반 프로젝트 운영 스냅샷이며, 정확한 항목별 시각은 표에 기록했다.

## 후속 개선

- 운영 공개 fundamentals 응답이 `listedShares`를 실제로 포함하는지 스키마/API 설정을 조사하고, 미포함 원인을 수정할 때 이 7개로 재발 여부를 확인한다.
- 자동 감지: 인증된 GET으로 소수 활성 미국 보통주 샘플을 요청해 응답 필드 `listedShares`의 존재와 양수 여부를 확인한다. 후보 추출 시 주식수 결측 수를 집계하고, 결측이 한 건이라도 있으면 결과 상태를 부분 결과로 표시한다.
- 남은 위험: 현재 응답에는 상장주수가 없으므로 주식 수 요건과 만/억 환산값은 미확정이다. 스냅샷은 2026-10-14 관측값으로 이후 거래에서 가격·시총 조건이 달라졌을 수 있다.
