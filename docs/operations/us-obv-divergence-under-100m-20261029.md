## 데이터 한계

- 운영 `GET /api/scan/us-obv-divergence`는 현재 404로 아직 배포되지 않았다. 그래서 설계된 공개 다이버전스 스냅샷 API가 아니라 운영 fundamentals/daily-candles 공개 GET을 읽고 로컬 v4 계산 함수를 적용했다. 운영 데이터 변경이나 갱신 요청은 하지 않았다.
- 후보 35개는 단건 daily-candles GET으로 한 번 더 읽어 각 종목의 최신 `dataUpdatedAt`을 확인했다. JSON의 `candleMetadata`에는 계산에 사용한 모든 봉의 거래일을 기록했지만 API는 종목별 최신 fetchedAt 하나만 제공하고 봉별 fetchedAt은 제공하지 않아 각 봉의 `dataUpdatedAtUtc`는 null이다. 공통 봉 메타데이터 요구와 완전히 일치하지 않는 API 한계다.
- 시총 스냅샷은 관측시각을 후보별로 보존했으며 실시간 값이 아니다. 원천 일봉의 split/dividend 조정 보장도 확인되지 않아 설계대로 `UNVERIFIED_CORPORATE_ACTION_ADJUSTMENT`로 표시한다.
- 후보 세부 지표와 원자료는 같은 디렉터리의 JSON에 기록했다.
