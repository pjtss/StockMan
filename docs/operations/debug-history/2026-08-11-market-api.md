## 재현 명령

관리자 로그인 쿠키를 가진 세션에서 다음을 호출한다.

```text
GET /api/admin/market-debug?market=kr
GET /api/admin/market-debug?market=kr&run=true
```

응답의 `requestId`, `sync.details`, `scan.failureCount`, `scan.results[].error`를 함께 보관하면 다음 장애에서도 API 원본 오류와 DB 캐시 문제를 구분할 수 있다.
