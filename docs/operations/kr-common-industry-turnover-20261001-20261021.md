# 국내 보통주 업종별 거래대금 비중 — 2026-10-01~2026-10-21

> **대체됨 (2026-10-25):** 이 문서는 당시 로컬 DB에 실제 거래대금이 없어 `종가×거래량`으로 계산한 근사치다. 종목별 공식 KIS 거래대금으로 다시 산출한 2026-10-01~23 결과는 [최신 보고서](./kr-common-industry-turnover-kis-20261001-20261023.md)에 있다. 이 문서의 값은 공식 거래대금 통계로 사용하지 않는다.

## 목적과 산출 기준

국내 활성 보통주를 대상으로 업종별 일별·주별·월별 거래대금과 해당 기간 합계 대비 비중을 계산했다. 자료는 사용자 로컬 PostgreSQL의 `kr_common_stock_universe` 및 `kr_instrument_universe_candles`에서 읽었으며 쓰기는 수행하지 않았다.

- 대상: enabled=true, instrument_type='COMMON_STOCK', KOSPI·KOSDAQ
- 업종: 로컬 KIS 종목 마스터의 시장별 `bstp_larg_div_code`. 시장별 코드 공간을 구별하기 위해 CSV에서 시장명을 함께 표기했다. 이는 표준산업분류가 아니다.
- 거래대금: 저장된 봉에는 보고 거래대금이 없고 원본 payload도 비어 있어 종가×거래량(KRW)으로 추정했다. KIS 공식 일봉 API 샘플은 OHLCV를 제공하며 보고 거래대금 항목을 보여주는 기본 일봉 응답이 아니다. 따라서 실제 체결대금 통계와 일치한다고 볼 수 없다.
- 주별·월별: 각 저장 일봉의 추정 거래대금을 합산. 주는 월요일 시작.
- 시점: DB 최신 거래일 2026-10-21. 2026-10-01~21 사이 저장 봉이 존재하는 13거래일만 포함한다.

## 커버리지와 제한

- 활성 COMMON_STOCK DB 마스터: KOSPI 761, KOSDAQ 1,591 (합계 2,352)
- 기간 내 관측된 활성 보통주 고유 종목 2,024개. 제공된 2026-08-18 KIS 마스터의 일반주/DR 분류를 통과한 1,985개를 업종에 매핑했고, 39개는 마스터 매칭이 안 되거나 fail-closed 분류에서 제외했다.
- 마지막 거래일 봉 1,772개 중 가격·거래량 양수 1,764개를 계산했다.
- DB에 V160 표준산업 컬럼이 없어 KIS `standard_industry_name`을 이용한 KSIC 기반 산업 묶음은 산출하지 못했다. 활성 DB 유니버스는 2,352종목인데 체크인된 2026-08-18 마스터와 기간 내 종목 커버리지가 달라 코드/분류 누락도 있다.
- 거래대금 원천 부재, 공식 종목 분류 커버리지, 미분류 종목 때문에 이 수치는 전체 시장의 공식 거래대금 비중이 아니라 로컬 저장 봉 부분집합의 추정치다.

## 공식 KIS API 재검증 메모 — 2026-10-25

- KIS 공식 샘플과 프로젝트의 lib/kis-investor-flow.ts 경로를 기준으로 FHKUP03500100 국내업종 일자별지수 API를 재검증했다. 2026-10-01~21의 KOSPI 종합(0001), KOSDAQ 종합(1001) 및 예시 업종 코드 응답은 정상이며 13개 거래일의 output2.acml_tr_pbmn를 반환했다. KOSPI 종합의 2026-10-21 값은 18,441,435, KOSDAQ 종합은 5,282,050이다. 이 값만으로 보통주 종목만의 거래대금 분해가 검증되지는 않는다.
- FHPUP02140000 업종 목록 호출에서 KOSPI 입력은 지수 목록(시장/규모/업종/테마가 섞임)을 반환했다. KOSDAQ 입력 응답과 코드 교차 검증도 배타적 산업 매핑을 입증하지 못했다. 코드 표본에서 동일 숫자 코드가 시장 파라미터에 따라 같은 업종명과 같은 거래대금을 내는 경우가 있어, 단순 시장별 분류 코드 추론은 안전하지 않다.
- KOSPI 업종 코드에는 금융/증권·보험, 제조와 하위 산업처럼 상하위 또는 분리 관계가 있어 코드 범위를 모두 더하면 중복될 수 있다. KOSDAQ도 업종/하위 업종 코드 체계가 달라 단순 범위 수집으로 완전하고 배타적인 산업 집합을 만들지 못했다. acml_tr_pbmn 값 단위와 업종별 지수가 보통주만을 구성하는지 공식 설명으로 독립 확인하지 못했으므로 원화 환산을 단정하지 않는다.
- 결론: 앞의 일·주·월 CSV는 계속 근사치로 취급해야 하며, 이번 KIS 지수값으로 업종별 보통주 통계를 대체하지 않았다. 정확한 결과에는 배타적인 공식 업종 코드표와 단위 설명, 또는 공식 종목별 거래대금 원자료와 활성 COMMON_STOCK 분류를 결합한 전체 커버리지가 필요하다.
- 자격증명과 응답 토큰을 출력하지 않고 KIS GET만 수행했다. 임시 토큰 파일은 삭제했고 DB/API 저장은 하지 않았다.
