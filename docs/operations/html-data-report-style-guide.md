# 독립형 HTML 데이터 보고서 스타일 기준

이 문서는 분석 결과를 브라우저에서 읽고 탐색할 수 있는 독립형 HTML 보고서의 기본 형식이다. 새 보고서를 만들거나 기존 보고서를 확장할 때 이 기준과 [국내 보통주 산업별 거래대금 예시](../../reports/kr-industry-turnover-20d.html)를 함께 참고한다. 주제와 데이터에 맞게 구성은 조정하되, 사실의 출처·단위·비교 기준을 분명히 하고 사용자가 표와 그래프를 함께 검토할 수 있게 한다.

## 시각 언어

- 한국어 문서는 `lang="ko"`, UTF-8 문자셋, 시스템 한글 글꼴을 사용한다.
- 전체 바탕은 밝은 청회색(`#f3f6fa`), 본문 카드는 흰색, 제목 영역은 짙은 남색(`#132b46`)으로 구성한다. 기본 글자색은 남색(`#172b43`), 보조 글자색은 회청색(`#65758b`), 경계선은 옅은 회색(`#dce4ee`)이다.
- 차트 강조색은 청록(`#087f74`), 파랑(`#3475ad`), 주황(`#c17d22`), 보라(`#8159a8`), 빨강(`#bb5b51`) 계열을 쓴다. 여러 계열을 함께 그릴 때 색만으로 구분하지 말고 범례·라벨도 제공한다.
- 콘텐츠 폭은 큰 화면에서 약 1,240px 이내로 제한하고 중앙 정렬한다. 섹션 간격과 흰 카드의 여백을 두어 숫자·그래프·표가 한 덩어리로 뭉치지 않게 한다.
- 제목, 짧은 설명, 기간·시장·분류·원천 메타데이터 순으로 보고서 맥락을 먼저 보여준다. 핵심 규모를 빠르게 파악하는 요약 지표가 유용하면 제목 아래 카드로 배치한다.

## 권장 구성

분석 목적에 맞는 요소만 사용하며, 데이터가 뒷받침하지 않는 요약이나 차트는 추가하지 않는다.

1. **제목과 범위**: 주제, 대상, 기간, 분류 체계, 시장 또는 표본을 명시한다.
2. **핵심 요약**: 전체 합계·대상 수·기준일처럼 독해에 도움이 되는 값을 단위와 함께 표시한다.
3. **비교 그래프**: 순위나 구성비가 목적이면 막대그래프를 쓰고 값과 분모를 읽을 수 있게 라벨을 붙인다.
4. **시간 그래프**: 추이를 보여줄 때 실제 날짜와 단위를 표시한다. 규모 차이가 비교를 방해하면 기준일=100 같은 정규화 선택지를 제공하고, 그 기준을 함께 설명한다.
5. **전체 데이터 표**: 그래프에서 제외된 항목도 검토할 수 있도록 전체 범위를 제공한다. 정렬 순위, 단위, 변화율 기준, 표본 수를 열 제목이나 설명에 명확히 적는다.
6. **방법과 출처**: 원천 기관/API 및 필드, 조회·집계 기준, 누락·제외·미확인 항목, 계산 정의를 본문 하단에서 확인할 수 있게 기록한다.

## 상호작용과 접근성

- 산업·기간·분류 등 핵심 선택이 가능한 데이터라면 선택 상자나 검색을 제공하고, 표 항목 선택이 그래프 선택과 연결되도록 한다.
- 범례 항목은 마우스와 키보드로 켜고 끌 수 있도록 하고, 선택 상태를 `aria-pressed` 등으로 노출한다. 검색 필드와 선택 상자에는 보이는 레이블을 연결한다.
- 그래프는 SVG 또는 동등한 시맨틱 형식을 사용하고 제목·설명을 연결한다. 차트에서 정확한 값을 읽기 어려운 경우 같은 정보를 담은 표를 제공한다.
- 모바일에서는 카드와 컨트롤이 줄바꿈되도록 하고, 넓은 데이터 표는 가로 스크롤로 읽을 수 있게 한다. 축·단위·라벨이 화면 밖으로 잘리지 않는지 확인한다.
- 사용자가 선택한 값이나 데이터 요약이 동적으로 바뀌면 화면낭독기가 인지할 수 있는 상태 영역을 둔다. 불필요한 애니메이션은 피하고 reduced-motion 설정을 존중한다.

## 데이터와 배포 원칙

- 거래대금·가격·비율·주식 수는 실제 필드와 계산 정의에 맞춰 표시한다. 추정치, 정규화 지수, 비교 변화율은 실제 관측값과 구분해 이름과 기준을 붙인다.
- 그래프와 표는 같은 데이터 집합을 사용한다. 코드 작성 시 데이터 항목 수, 날짜 범위, 결측, 집계합계와 표시 단위를 검산하고 검증 근거를 작업 기록에 남긴다.
- 개인 정보나 자격증명을 HTML에 포함하지 않는다. 사용자 배포 목적에 별도 요구가 없으면 원자료의 출처와 기준 시점을 함께 제공한다.
- 독립 파일 전달을 요청받은 경우 HTML 한 파일에서 바로 열리도록 CSS·JavaScript·데이터를 내장하며, 외부 CDN이나 실행 시 네트워크 요청에 의존하지 않는다. 대용량 자료 때문에 이것이 불가능하면 이유와 파일 구성 안내를 명시한다.
- 저장 후 UTF-8 한글, 브라우저 콘솔, 주요 상호작용, 좁은 화면 레이아웃을 확인한다. 정적 HTML인 경우 제품 빌드·테스트를 임의로 수행하지 말고 실제 변경 범위에 맞는 검증을 기록한다.

## 적용 예시

- [국내 보통주 세부산업 거래대금 20거래일 그래프](../../reports/kr-industry-turnover-20d.html)는 어두운 제목 영역, 요약 카드, 누적 상위 12개 막대, 선택형 일별 그래프, 검색 가능한 전체 산업 표, KIS 원천 설명을 사용한다.
- [세부산업별 종목 거래대금 TOP 5](../../reports/kr-standard-industry-stock-top5-20260922-20261023.html)는 같은 시각 언어를 사용하며 산업 선택·검색, 산업별 TOP 5 막대와 표, TOP 종목 일별 선 그래프, 거래대금/첫 거래 보고일=100 전환, 종목별 일자·일봉 조회시각 및 전체·상세 CSV를 제공한다.
- 예시의 데이터 특화 요소(산업 선택, 첫날=100 보기, KIS 필드 표기)는 해당 산업 거래대금 보고서에만 필요한 기능이다. 다른 분석에서는 목적·원천에 맞게 바꾸고 시각 체계와 출처 설명 원칙을 이어간다.
