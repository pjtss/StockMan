# 미국 보통주 시총 USD 1,000만 미만 일봉 스냅샷

## 기준과 결과

- 기준 거래일: 2026-10-20 미국장 완료 일봉
- 스냅샷 추출: 2026-10-21 (UTC 기준 원본 시각은 JSON 메타데이터 참조)
- 시장: 프로젝트 유니버스의 NAS, NYS, AMS
- 종목: `us_common_stock_universe`에서 활성 `COMMON_STOCK`, USD 종목으로 확인된 항목
- 시가총액: 운영 `instrument-fundamentals`의 최신 양수 USD 스냅샷이 **10,000,000 이하**인 항목. 정확히 10,000,000달러인 행도 포함한다.
- 일봉: 운영 DB의 KIS 기반 캐시를 read-only GET으로 조회했다. 포함 행은 2026-09-21~2026-10-20 사이 18개 이상 일봉을 보유한다.
- 결과: 209종목 — NAS 181, AMS 27, NYS 1. 스냅샷에서 기준 경계값과 같은 종목은 0개였으며 최대 시총은 9,982,955달러다.

- 목록은 현재 파일 스냅샷이다. 현재 구성원/시총으로 사용하기 전 최신 운영 스냅샷을 다시 추출하고 보통주 활성 상태를 재확인한다.

## 해석 및 한계

- 시총은 운영 fundamental snapshot 값이지 추출 시각의 실시간 시총이 아니다. 행별 `marketCapObservedAt`과 `marketCapFetchedAt`을 확인한다.
- SEC cover 원문 종류 감사가 완료된 56개 유니버스 차이 후보에서는 ADS/ADR를 제외하고 직접 보통주/ordinary share 확인된 20개만 보통주로 인정했다. 나머지 431개는 기존 프로젝트 공식 종목 마스터의 활성 `COMMON_STOCK` 분류를 근거로 삼았다. 프로젝트 마스터는 2026-09-25 기준이므로 최신 공식 종목 마스터 전체를 독립적으로 재검증한 결과는 아니다.
- 시총 또는 보통주 분류가 없거나 모호한 종목은 포함하지 않는다. 달러 환산·결측값 추정은 하지 않는다.
- 일봉 데이터는 원천 제공자의 기업행사 조정 여부를 별도 재구성하지 않은 저장 봉이다. 비정상 OHLC 및 역분할 영향은 원본 값으로 남는다.

## 다시 꺼내 쓰기

이 기준 결과를 요청할 때 “2026-10-20 미국 시총 1,000만 달러 미만 보통주 일봉 스냅샷”이라고 지정하면 상세 JSON을 읽는다. 오늘 기준 결과가 필요하면 [미국 소형 시가총액 종목 추출 운영 절차](./us-small-cap-extraction.md)에 따라 운영 read-only GET으로 시총·관측시각을 새로 받고, 최신 완료 일봉도 다시 조회해 동일 기준으로 저장한다. 프로젝트에서 제공하는 공통 봉 메타데이터 규칙(거래일시, 데이터 갱신일시, 종목명, 종목코드)을 출력/API에도 유지한다.
