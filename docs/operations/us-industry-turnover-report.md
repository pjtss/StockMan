# 미국 보통주 산업별 거래대금 월간 집계

`GET /api/admin/us-industry-turnover`는 관리자 세션으로 보호되는 읽기 전용 보고 API다. 운영 `us_common_stock_universe`와 `us_instrument_universe_candles`를 서버 내부에서 조인해 가장 최근 일봉 날짜 기준 직전 달력 1개월을 집계한다. API 사용자는 운영 DB에 직접 접속하지 않는다. 프록시 요청시간을 제한하기 위해 종목 정렬 후 200개씩 처리하며, 다음 페이지는 `nextOffset` 값으로 요청한다. 첫 요청은 기간 캔들 커버리지를 계산하고 뒤이은 요청에는 `coverage=false`를 붙여 해당 검사를 생략한다. 페이지 합산 전 `startDate`, `latestDate`, 전체 eligible 수가 모든 응답에서 같은지 확인한다.

## 포함 범위와 계산

- 활성·일봉 대상이며 공식 종목 마스터에서 `COMMON_STOCK`인 미국 보통주만 포함한다. NAS, NYS, AMS 시장이며 ETF, 레버리지·인버스, 워런트, 파생, DR을 제외한다.
- 분류 그룹은 `classification_source + industry_code`다. `SEC_EDGAR_SIC`로 저장된 코드는 `SEC_SIC`, 나머지 저장 코드는 `KIS_ICOD`로 나눈다. 코드 체계가 다르므로 두 분류의 같은 숫자 코드를 합치지 않는다.
- 거래대금은 일봉의 `trading_value`를 우선 사용한다. 값이 없거나 0이면 `close × volume`을 보조 계산값으로 쓴다. 응답에 원천 사용 행 수를 포함한다.
- 응답에는 현재 종목 페이지의 기간 합계, 거래일별 추이, 분류 코드 미분류 그룹 및 전체 대상·캔들 보유 종목 수가 포함된다. 금액 단위는 USD다. 전체 보고서는 각 페이지의 동일 `classification_source + industry_code + date` 값을 합산해 만든다.
- 저장 데이터에는 KIS 업종 코드 설명과 SEC SIC 설명이 함께 보장되지 않으므로 그룹은 출처와 코드로 식별한다. 이름이 필요한 보고서는 공식 코드 설명 사전을 별도로 확보하기 전까지 임의 라벨을 붙이지 않는다.

## 남은 한계 및 후속 개선

- 거래대금 필드가 비어 있을 때 `close × volume`은 종가 기준 추정치이며 체결별 거래대금 합과 일치하지 않을 수 있다.
- 캔들이 없는 보통주는 집계 금액에 들어가지 않으며 `eligibleWithPeriodCandlesCount`와 전체 보통주 수를 비교해 데이터 커버리지를 확인한다.
- 운영 조회 전 API 변경은 배포 게이트를 통과하고 운영 서버에서 배포 후 확인되어야 한다. 정기 검증에는 분류 원천별 자격 종목 수, 캔들 커버리지, 거래대금 원본/대체 계산 비중을 포함한다.
- 읽기 쿼리가 프록시 제한시간을 초과하면 한 API에서 전체 종목을 다시 처리하지 말고 페이지 크기를 유지한 채 offset 단위로 읽는다. 각 페이지의 진행 여부와 응답시간을 기록하고 마지막 `nextOffset=null`에서 완결 여부를 확인한다.
