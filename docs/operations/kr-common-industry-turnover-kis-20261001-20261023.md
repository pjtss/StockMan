## 집계 방법과 범위

- **자료 기준일·최신 거래일 확인**: 2026-10-25 KIS 공식 API를 삼성전자(005930)와 SK하이닉스(000660)로 read-only 재조회했다. 응답은 둘 다 2026-10-23까지만 봉을 반환했으며 10-24~25 추가 거래일 자료는 없었다. 10-25는 일요일이므로 본 보고서의 최신일 10-23을 최신 응답 거래일로 확인했다.

- **거래대금 원천**: KIS 국내주식 기간별 시세 API `inquire-daily-itemchartprice`, TR `FHKST03010100`, 응답 `output2.acml_tr_pbmn`. 요청은 읽기 전용 GET이며 `FID_COND_MRKT_DIV_CODE=UN`(통합 KRX+NXT), 수정주가 원구분 `FID_ORG_ADJ_PRC=1`을 사용했다. KIS의 공식 샘플은 일/주/월/년 구분 조회를 설명한다: [공식 API 샘플](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/inquire_daily_itemchartprice.py).
- **종목 유니버스**: 2026-10-24 KIS 공식 KOSPI/KOSDAQ 마스터 2,548개. 마스터 상품 분류 중 ST(주권) 2,536개와 FS(외국주권) 12개를 보통주로 포함하고, 우선주·DR·ETF/ETN 등 ETP·워런트·권리를 제외했다. 2,548종목 모두 조회 성공. 마스터 파일과 checksum은 [KIS 마스터 보관소](../references/kis-instrument-masters/README.md)에 기록했다.
- **업종 분류**: KIS 공식 종목 마스터의 `bstp_larg_div_code` 대분류를 사용했다. 시장별 업종코드는 같은 KIS 대분류명인 경우 합쳤다. 이는 KIS 시장 분류이며 한국표준산업분류(KSIC) 또는 KRX 산업분류와 동일한 체계라고 보장하지 않는다. 코드 `0000`은 ‘분류 없음’으로 별도 유지해 분모에서 빼지 않았다.
- **기간 집계**: 일별은 해당 날짜 보고 거래대금 합계, 주별은 월요일 시작 주의 일별 합계, 월별은 달력 월의 일별 합계다. 해당 종목 응답에 특정 일자의 봉이 없으면 해당일 보고 거래대금은 0으로 기여한다. 15거래일 목록은 `summary JSON`에 보존했다.
- **유니버스 차이**: 같은 작업에서 로컬 활성 보통주 DB는 2,352개, 운영 상태 API는 2,358개를 보고했다. 본 통계는 사용자가 요청한 국내 전체 보통주 시장 범위를 위해 최신 공식 KIS 마스터의 2,548개를 기준으로 했다. 로컬 DB에 없는 공식 마스터 종목 196개도 직접 조회했다. 두 운영/DB 수치 간 6개 차이는 해당 집계 원천만으로 원인을 확정할 수 없으므로 미해결 운영 유니버스 차이로 남긴다.

## 검증·제한

- 전체 공식 마스터 2,548종목의 조회 성공 건수 2,548, API 실패 0건. 대부분은 15개 거래일을 포함했고, 기간 중 신규 상장 등으로 바 수가 적은 종목은 응답된 거래일만 합산했다.
- 일·주·월 CSV의 업종별 금액을 기간별로 합산하면 각 기간 분모와 일치한다. 금액은 원 단위 정수로 보존했고 비중은 소수점 넷째 자리까지 반올림했으므로 표시 비중 합계는 100%와 최대 약 0.001%p 차이가 날 수 있다.
- **기존 2026-10-01~21 로컬 DB 보고서는 근사치**다. 해당 봉에 실제 거래대금이 없어서 종가×거래량으로 계산한 값이며, 이 보고서의 공식 API 값과 혼용하면 안 된다. 기존 문서 첫머리에 대체 안내를 추가했다.
- 현재 거래대금 API의 시장코드, 필드 의미, 보통주 분류는 KIS 자료에 따른다. 거래소 전체 시장 통계와 정의/집계 경계가 다를 수 있으므로 KRX 공식 총계와 동일하다고 단정하지 않는다.
