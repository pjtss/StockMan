# StockMan UI 디자인 시스템 개선안

## 목표

현재의 다크모드와 네온 그린 정체성은 유지하면서, 화면 간 정보 계층·상태 표현·모바일 사용성을 일관되게 만든다. 네온 효과는 주요 상태와 행동을 강조하는 용도로만 사용하고, 본문 가독성을 우선한다.

## 토큰

- 배경 계층: `--background`(전체), `--secondary`(섹션), `--card`(카드)
- 텍스트 계층: `--foreground`(본문), `--text-secondary`(설명), `--text-muted`(메타)
- 상태 색상: `--neon-green`(성공/활성), `--neon-blue`(정보), `--neon-red`(위험), 앰버(주의)
- 공통 포커스: primary 색상 3px 외곽선
- 터치 영역: 모바일 인터랙션 요소 최소 44px
- 반경: 작은 컨트롤 10~12px, 카드 16~20px

## 컴포넌트 규칙

1. 페이지는 `hero → toolbar → content → empty/error` 순서를 따른다.
2. 카드 안에서 제목·식별자·수치·행동 영역을 분리한다.
3. 로딩, 성공, 빈 결과, 오류는 서로 다른 문구와 시각 상태로 표현한다.
4. 위험 작업은 네온 레드와 확인 절차를 사용한다.
5. 종목 화면은 회사명·티커·시장·갱신시각을 하나의 identity block으로 표시한다.
6. 숫자는 우측 정렬하고, 긴 회사명은 안전하게 줄바꿈 또는 말줄임 처리한다.

## 우선 적용 범위

- `/charts`: 추출 조건 toolbar와 결과 카드의 상태·간격·포커스 개선
- `/watchlist`: 선택·전체 선택·일괄 삭제 상태를 카드와 toolbar에 일관되게 적용
- 뉴스/공시: 날짜·출처 필터와 JSON 복사 상태를 동일한 control 스타일로 통합
- 차트 모달: 모바일 닫기 버튼, 회사명/티커 identity, 차트 설정 유지

## 반응형·접근성

- 600px 이하에서는 단일 열과 세로형 toolbar를 사용한다.
- 색상만으로 상태를 구분하지 않고 텍스트·아이콘을 함께 사용한다.
- `:focus-visible`을 모든 버튼, 링크, 입력 컨트롤에 적용한다.
- `prefers-reduced-motion`에서는 glow·transform 애니메이션을 줄인다.

## 적용·검증 순서

전역 토큰과 공통 primitive를 먼저 정리한 뒤 `/charts`, `/watchlist`, 차트 모달 순서로 적용한다. 각 단계마다 관련 Vitest, `npm run typecheck`, `npm run build`를 실행하고 모바일 폭에서 overflow와 터치 영역을 확인한다.
