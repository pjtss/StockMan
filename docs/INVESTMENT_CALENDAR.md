# 투자 일정 캘린더

## 목적

IPO, 실적 발표, 배당락일처럼 날짜가 핵심인 이벤트를 출처별 원문과 함께 하나의 정규화 테이블에 저장하고, 사용자가 시장·기간·일정 유형으로 빠르게 필터링한다.

## 저장 모델

`investment_calendar_events`가 공통 이벤트 저장소다. `source + external_id`를 유일 키로 사용해 수집 재실행 시 중복을 방지한다. `raw_payload`에는 원천 응답을 보존하고, 화면에는 `event_date`, 종목명·티커, 제목, 출처만 우선 노출한다.

지원 유형:

- `IPO`: 신규 상장·공모 관련 일정
- `EARNINGS`: 실적 발표 일정
- `EX_DIVIDEND`: 배당락일
- `DIVIDEND_PAYMENT`: 배당 지급일
- `SHAREHOLDER_MEETING`: 주주총회
- `LOCKUP_EXPIRY`: 보호예수 해제

## 수집 경계

원천별 포맷이 달라 수집기는 원천 어댑터와 정규화 적재를 분리한다. 어댑터는 `POST /api/investment-calendar`에 `x-cron-secret`을 넣어 최대 5,000건을 배치 적재한다. DART 자동화 실행 시 당일 DART 공시 중 실적·배당·주주총회·보호예수 항목은 자동으로 정규화해 함께 저장한다. IPO와 해외 일정은 같은 배치 계약으로 독립 어댑터를 연결한다.

## UI

`/investment-calendar`에서 45일 기본 범위, 시작·종료일, 시장, 유형 칩 필터를 제공한다. 날짜별 타임라인으로 그룹화하며 모바일에서는 날짜와 이벤트 카드를 세로로 쌓는다. 원문 링크가 있으면 카드에서 바로 열 수 있다.

## 운영 원칙

- 원천 일정이 변경되면 동일한 외부 ID로 UPSERT한다.
- 확정일과 예상일은 어댑터가 `description`과 `raw_payload`에 명시한다.
- 출처와 수집 시각을 항상 보존한다.
- 데이터가 없을 때 임의의 일정이나 Mock을 표시하지 않는다.
