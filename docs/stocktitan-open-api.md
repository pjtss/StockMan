# StockTitan Open API 제공 현황

## 결론

2026-10-06 확인 기준, StockTitan은 개발자용 공개 Open API를 제공하지 않는다고 공식 FAQ에서 밝힌다. 따라서 공개된 API 종류, REST 엔드포인트, 인증 방식, 응답 스키마 또는 개발자용 API 상품은 확인되지 않는다. StockTitan 데이터와 기능은 웹 인터페이스 및 모바일 최적화 PWA를 통해 제공된다.

## 연동 가능한 제공 내역

| 구분 | 제공 여부 | 제공 내역 및 범위 |
| --- | --- | --- |
| 개발자용 공개 Open API | 미제공 | 공식 FAQ에 “Stock Titan does not offer a public API”라고 명시되어 있다. 공개 API 엔드포인트/명세는 없다. |
| RSS 피드 | 제공 | 공식 약관은 StockTitan이 제공하는 RSS 피드를 제3자 애플리케이션에 통합할 수 있는 허용된 데이터 수집 방법으로 명시한다. 이는 REST Open API와는 별도다. |
| 웹 인터페이스 / PWA | 제공 | 뉴스, 공시, 시장 데이터 및 플랫폼 기능을 웹사이트와 모바일 최적화 PWA에서 이용한다. |

공식 FAQ가 소개하는 웹 제품의 데이터·기능 범위에는 회사 보도자료 뉴스 피드, SEC 공시 피드, Momentum Scanner, 기본 일봉 차트, 상승·하락 종목 추적 등이 포함된다. FDA 승인/거절 및 임상시험 뉴스, 실적 뉴스, 거래정지 추적, 주식분할 일정, 재무정보 등의 화면도 제공한다고 설명한다. 이 기능 목록은 **웹 제품 기능**이며 API 엔드포인트 목록으로 해석하면 안 된다. 무료 요금제는 뉴스/SEC 피드 1분 지연, Momentum Scanner 15분 지연으로 안내되며 유료 플랜별 지연·기능은 달라질 수 있다.

## 이용 및 제한

- RSS가 필요한 경우 StockTitan이 제공하는 RSS URL을 사용한다. 이 프로젝트에서 확인한 기존 기본 피드는 `https://www.stocktitan.net/rss`이다.
- 약관은 무단 웹 스크래핑과 사이트 자동 데이터 추출을 금지하고, 허용된 외부 연동 방식으로 제공 RSS를 명시한다. RSS 외 사이트 화면·내부 요청을 자동 수집하는 방식은 공식 API로 간주할 수 없다.
- 상업적 이용 또는 별도 데이터 라이선스가 필요한 경우 StockTitan에 직접 문의해 서면 허가/계약 범위를 확인한다.

## 범위와 검증

공식 FAQ와 이용 약관의 공개 문구를 확인해 정리했다. 비공개 파트너 API, 개별 계약 API 또는 향후 제공 여부는 공개 페이지만으로 확인할 수 없으며, 본 문서에는 공개적으로 확인 가능한 범위만 기록한다. 코드 변경, 테스트/빌드/실행, 커밋·푸시·배포는 수행하지 않았다.
