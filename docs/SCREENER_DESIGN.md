# 통합 종목 추출기 설계

## 정책
- 국내·해외 모두 `COMMON_STOCK` 및 `ACTIVE` 유니버스만 사용한다.
- 국내 시가총액 하한은 기본 300억 원이다.
- 일반 이동평균은 EMA만 사용한다. 볼린저밴드는 기존 20기간·2표준편차 정의를 유지한다.
- 기준일은 각 시장의 저장된 최신 완료봉이며, 미래 데이터는 사용하지 않는다.

## 입력
`market`, `exchange`, `instrumentType`, `status`, `asOf`, `filters`, `ranking`, `limit`을 받는다. 필터 field는 `marketCap`, `D/W/M.close`, `D/W/M.volume`, `D/W/M.rvol`, `D/W/M.ema9`, `D/W/M.bb.upper|middle|lower|width`를 지원한다.

## 실행 단계
유니버스 필터 → 시총 필터 → 필요한 봉만 로드 → 지표 1회 계산 → AND/OR 조건 평가 → 점수·정렬 → 표준 메타데이터 응답.

## 결과
종목명·코드·시장·거래소·시총·통화·기준봉 일시·봉 갱신일시·실제값·조건별 판정·탈락 사유를 반환한다.

## 검증
DB 통합 테스트는 빈 데이터, 기준일 불일치, NULL 시총, 데이터 부족, 복수 시장, 조건 실패를 포함한다.

## 봉 갱신 관측·운영 디버깅
일봉은 KIS 직접 수집하고 주봉·월봉은 저장된 일봉에서 국내·해외 모두 로컬 집계한다. 실행 이력은 시장·봉 주기별로 `startedAt`, `finishedAt`, `durationMs`, 대상·성공·실패·저장 캔들 수를 독립 기록한다. 재시도 키는 반드시 `market:code:timeframe`으로 비교한다. 최신성은 전체 테이블의 MAX가 아니라 종목별 최신 거래일과 시장 기준 최신 거래일을 비교한다.
