# 드래곤 위협 연출 모듈

화면 중앙에서 거대한 드래곤이 등장해 입을 크게 벌리고 위협한 뒤 사라지는 캔버스 오버레이 모듈이다.

- `/charts` 진입 시 한 번 실행
- 등장·위협·정지·퇴장 단계로 구성
- 눈빛, 뿔, 턱, 이빨, 입 안의 색 대비로 다크 판타지 연출
- 화면 크기에 맞춰 자동 스케일
- `pointer-events: none`으로 기존 화면 조작을 방해하지 않음
- `prefers-reduced-motion` 사용자에게는 짧은 연출 적용

폭죽 모듈은 `/charts` 진입 흐름에서 해제했으며, 재사용 가능한 `FireworksOverlay` 자체는 다른 축하 이벤트를 위해 보존한다.
