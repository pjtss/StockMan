# 국내 보통주 시총 1조 원 이하·RVOL≥2 추출 운영 기준

## 목적

최신 확정 거래일의 일봉 캐시에서 국내 활성 보통주 중 시총 1조 원 이하이고 거래량 RVOL이 2 이상인 종목을 추출해 날짜별 결과 문서로 관리한다. 결과는 거래량 급증 후보이며 주가 방향이나 수익을 보장하지 않는다.

## 적용 범위와 필터

1. 대상은 공식 종목 마스터의 `enabled=true`, `daily_active=true`, `instrument_type='COMMON_STOCK'`인 KOSPI·KOSDAQ 종목으로 제한한다. 분류나 활성 상태를 확인할 수 없는 종목은 포함하지 않는다.
2. 프로젝트 국내 시총 하한 원칙을 적용해 300억 원 초과, 사용자 상한 1조 원 이하로 필터한다. 시총 통화가 KRW가 아니거나 시총이 누락·0 이하인 종목은 제외한다.
3. 시총은 종목별 최신 `instrument_fundamental_snapshots` 값을 사용한다. 보고서에는 각 종목의 `observed_at` 날짜를 기록한다. 시총 기준일이 서로 다르거나 최신 거래일과 차이가 있으면 그 차이를 요약에 명시하고, 최신 시총 전수 검증으로 표현하지 않는다.
4. 시장별 최신 저장 거래일을 확인한다. KOSPI와 KOSDAQ의 최신 거래일이 다르면 공통 기준일로 낮추고 이를 문서에 적는다. 장중 미완료 봉은 사용하지 않는다.
5. RVOL은 `기준일 거래량 ÷ 기준일 이전 최근 20개 양수 거래량 일봉 평균`이다. 기준일 봉은 분모에서 제외한다. 기준일 거래량이 0이면 계산하지 않는다. 직전 양수 거래일 봉이 20개 미만이면 RVOL 미산출로 집계하고 후보에 포함하지 않는다.
6. RVOL≥2 종목을 RVOL 내림차순으로 정렬한다. 동률은 시장과 종목코드 오름차순으로 둔다.

## 일봉 수집 및 실패 처리

- 우선 로컬 일봉 캐시의 최신성과 대상 커버리지를 확인한다. 운영 캐시 동기화에 실패하거나 종목별 봉이 누락되면 실패 수와 누락 코드를 보존하고, 불완전한 결과를 전수 목록으로 표현하지 않는다.
- KIS 보완 수집은 프로젝트 국내 일봉 모듈의 규격을 따른다: `GET /uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice`, `tr_id=FHKST03010100`, 일봉 기간 코드 `D`. 상세 endpoint와 파라미터는 [한국투자증권 공식 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_daily_itemchartprice/inquire_daily_itemchartprice.py)를 기준으로 한다.
- KIS 응답은 HTTP 성공과 `rt_cd=0`을 확인한 뒤 저장한다. 기존 유효 토큰을 재사용하며 토큰 발급 이력·요청 속도 정책을 지킨다. 토큰·앱키·시크릿을 로그나 문서에 쓰지 않는다.
- 저장 후 대상 universe와 기준일 봉을 조인해 전수 커버리지를 다시 검사한다. 보완 봉은 출처를 기록한다. HTTP·KIS 오류나 DB 저장 검증 실패가 있으면 후보 결과를 부분 결과로 표시하고 실패 수를 적는다.

## 결과 문서 필수 항목

날짜별 보고서는 `docs/operations/kr-rvol-2-marketcap-1t-YYYYMMDD.md` 형식으로 관리한다. 다음을 포함한다.

- 공통 최신 거래일과 사용한 보통주·시총 기준
- 전체 적격 종목 수, 기준일 봉 커버리지, 0 거래량·미산출·실패 건수
- 종목별 시총 관측일과 값, 거래일, 종가, 거래량, 이전 20봉 평균, RVOL, 봉 갱신시각(KST)
- 시총 시점 차이와 데이터 출처·오류를 포함한 한계
- 해당 날짜 보고서와 이 runbook 링크를 `docs/README.md`에 추가
- 작업 목적, 변경·조회 대상, 검증, 커밋·푸시·배포 여부를 `DEVELOPMENT_LOG.md`에 기록
