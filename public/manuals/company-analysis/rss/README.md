# 다국가 RSS 링크 분석 아카이브

<!-- catalog-description: 사용자가 여러 시장의 RSS·보도자료 링크를 함께 제공했을 때 사건 단위로 중복 제거하고 근거·판정·coverage를 기록하는 날짜별 아카이브입니다. -->

이 보관소는 미국·대한민국 기업 dossier와 별개로, 사용자가 전달한 다국가 뉴스 링크 묶음을 날짜별로 정리한다. 기사/재게시 링크는 동일 사건으로 묶되 입력 URL과 원문 근거를 보존한다. 호재로 판정할 때는 회사·거래소·규제기관의 공식 원문을 우선한다.

## 분석 기록

- 2026-11-04: 사용자 제공 뉴스 링크 묶음 검토 기록이 있다. 상세 날짜별 결과 파일은 로컬 프로젝트 작업 기록으로만 관리하며 공개 매뉴얼 카탈로그에 싣지 않는다.

## 기록 규칙

- 파일명은 `rss-link-analysis-YYYY-MM-DD.md`로 한다. 기준일은 분석 요청의 날짜이며 시간대가 다르면 문서에서 별도로 밝힌다.
- 문서 첫 부분에 입력 URL 수, 고유 사건 수, 원문 확인 범위, 중복/미분석 건수를 구분해 기록한다.
- 사건마다 회사/티커, 방향, POSITIVE일 때만 강도, 근거 수치, 확정/추정 시점, 공시 리스크, confidence와 출처를 남긴다.
- 제목만 확인한 항목은 분석 완료로 집계하지 않고 `미확인` 또는 `판정 보류`로 표시한다.
- 공시 기반 리스크를 조사하지 않은 경우 `이번 범위 미검토`라고 쓰며, 리스크 부재를 추정하지 않는다.
- 누적 분석 기준은 상위 [`rss-bullish-analysis-standard.md`](../rss-bullish-analysis-standard.md)와 [운영 런북](../../operations/llm-rss-bullish-report-runbook.md)을 따른다.

날짜별 결과 파일은 `docs/company-analysis/rss/rss-link-analysis-YYYY-MM-DD.md` 형식으로 로컬에 보존한다. 운영 보고서가 아니며 운영 RSS/API에 저장하거나 알림으로 보내지 않는다.
